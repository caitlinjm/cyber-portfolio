## Project 2: Apply Filters to SQL Queries
In this project, I focused on querying and isolating specific security event data. I applied SQL filtering techniques using `WHERE` clauses alongside operators like `AND`, `OR`, and `NOT` to analyze login attempts, track employee access levels, and investigate potential security incidents.
